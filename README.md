## Project Description

This project is a simple command-line line editor developed using C. It allows the user to insert, delete and display lines of text using a menu-driven interface.

## Features

* Insert Line
* Delete Line
* Display Document
* Handles invalid line numbers
* Handles an empty document

## Data Structure

The program uses a two-dimensional character array to store the lines of the document.

## How to Compile

Open the terminal in the project folder and run:

```bash
gcc line_editor.c -o line_editor
```

## How to Run

On Windows:

```bash
line_editor
```

On Linux/macOS:

```bash
./line_editor
```

## Menu Options

1. Insert Line
2. Delete Line
3. Display Document
4. Exit
